# Retail Sales Data Agent

## Project Overview

The Retail Sales Data Agent was created to analyse retail sales data and answer business-related questions using the available dataset.

## Dataset

The dataset contains the following fields:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Analysis

The Data Agent was used to analyse:

- Total sales and revenue
- Best-selling product categories
- Customer purchasing behaviour
- Sales by gender
- Sales by age group
- Monthly sales trends
- Quantity of products sold

## Tools and Skills

- SQL
- Data Analysis
- Data Cleaning
- Data Agent
- Business Analysis

## Conclusion

The Retail Sales Data Agent performed well in analysing the dataset and answering sales-related questions. It successfully identified sales trends, product performance and customer purchasing patterns. Some questions required clearer instructions and the correct selection of data fields to produce accurate results.
